# TJA-Gen

音源と設定から太鼓の達人用のTJA譜面を生成する、依存なしのブラウザーアプリです。音源解析はブラウザー内で行います。

## 起動方法

`index.html` をモダンブラウザーで開いてください。音源はブラウザー内で処理され、サーバーにはアップロードされません。MP3などの圧縮音源を使う場合は、デコード対応のため Chrome、Edge、Firefox の利用をおすすめします。

## 使い方

1. 音源ファイルを選択します。
2. BPMは音源から自動推定されます。合わない場合は入力欄を修正します。
3. 曲名、コース、目標密度（打/秒）、1小節の分割数を設定します。
4. 「譜面を生成する」を押し、生成結果を確認してTJAをダウンロードします。
5. ダウンロードしたTJAと元の音源を同じフォルダーに置きます。

## 生成方式

生成方式は画面で切り替えられます。

- **学習モデル（実験版）**: `trained-model.js`の分類器に加え、譜面から集計した音符間隔、小節内アクセント、ドン/カツの遷移傾向を使って並びを整えます。
- **音量ベース（比較用）**: 音の立ち上がりを検出し、目標密度に合わせてノーツを配置します。

目標密度は曲全体の1秒あたりの平均打数です。「1小節の分割数」は休符も含む音符配置枠の数（1〜256）です。たとえば256なら各小節を256文字で出力し、各位置に音符または休符を配置します。枠数に応じて最低48分音符相当の間隔（`ceil(分割数 / 48)`枠以上）を空けます。無音・小音量部分は候補から除き、目標打/秒から曲全体のノーツ数を求めて音の活動がある小節に配分します。さらに音源特徴と学習した譜面の間隔・アクセント・ノーツ遷移に合う枠を選びます。指定密度が小節の枠数・最低間隔・音の活動量で実現できる上限を超えた場合、実際の密度は設定値より低くなります。隣接小節は同じ配置の単純反復になりにくくし、4小節後にはフレーズを再現する傾向を加えています。設定密度からTJAの★レベルも概算します。BPM検出は音量の立ち上がりの周期性による推定値なので、半分/倍のBPMなどにずれる場合があります。入力欄で修正してください。

学習モデルは実験版です。評価用音源でのノーツ検出F1は約0.41で、曲の音楽性や譜面の遊びやすさを保証しません。出力譜面を必ず確認・調整してください。

## 音量ベース方式

音源を約10ミリ秒ごとのフレームに分け、チャンネルをまとめたRMS音量の増加をオンセット（音の立ち上がり）として検出します。BPMで区切った各小節を設定した数（最大256）の枠に分割し、音の立ち上がりが強い枠から目標打/秒に達する分のノーツを選びます。残りの枠は休符（0）として出力し、拍位置によりドン/カツを割り当てます。

## 手元の譜面で学習・評価する

学習にはNode.js、`ffmpeg`、Python 3、NumPyが必要です。データをリポジトリ外に置いたまま実行します。

```powershell
node tools\train-chart-model.mjs --data-dir "C:\Users\user\TJA-Gen-data" --python "C:\Path\To\python.exe"
```

標準では学習用音源を3周して重みを更新します。動作確認は`--limit 20 --epochs 1`、学習回数を明示する場合は`--epochs 5`のように指定します。特徴量はローカルの一時ファイルに作成し、学習成功後に削除します。曲名や譜面、音源をネットワークへ送信しません。学習モデルと集計レポートはデータフォルダー内の`.tja-gen-training`に保存されます。

学習完了後、検証済みのモデルだけをWebアプリへ反映します。

```powershell
node tools\train-chart-model.mjs --data-dir "C:\Users\user\TJA-Gen-data" --rhythm-only
node tools\package-web-model.mjs "C:\Users\user\TJA-Gen-data\.tja-gen-training\model.json"
```

`--rhythm-only`は音源を再解析せず、手元のTJA全件から音符間隔・小節内の配置位置・ドン/カツ遷移の統計を作ります。packageコマンドはこの統計を既存の音響モデルとまとめて`trained-model.js`に出力します。GitHub Pagesで誰でも使えるようにする場合は、このモデルファイルをアプリと一緒に公開します。譜面・音源・詳細レポートは公開せず、データフォルダー内に保持してください。

学習時はTJAのBPM変更・拍子変更を読み取り、分岐譜面、ディレイ、対応外の拍子やタイミング指定を含むチャートは除外します。音源のSHA-256が同じ譜面をまとめてから約20%を評価用に分けるため、同じ曲の別難易度が学習と評価にまたがりません。
