# TJA-Gen

音源と設定から太鼓の達人用のTJA譜面を生成する、依存なしのブラウザーアプリです。音源解析はブラウザー内で行います。

## 起動方法

`index.html` をモダンブラウザーで開いてください。音源はブラウザー内で処理され、サーバーにはアップロードされません。MP3などの圧縮音源を使う場合は、デコード対応のため Chrome、Edge、Firefox の利用をおすすめします。

## 使い方

1. 音源ファイルを選択します。
2. 曲名、BPM、コース、難易度を設定します。
3. 「譜面を生成する」を押し、生成結果を確認してTJAをダウンロードします。
4. ダウンロードしたTJAと元の音源を同じフォルダーに置きます。

## 生成方式

生成方式は画面で切り替えられます。

- **学習モデル（実験版）**: `trained-model.js`の分類器が、音量特徴・拍位置・BPM・コース・★から各16分音符のドン/カツ/大音符/休符を予測します。
- **音量ベース（比較用）**: 音の立ち上がりを検出し、一定の閾値でノーツを配置する従来方式です。

学習モデルの評価用音源におけるノーツ検出F1は約0.41です。これはまだ比較・改良段階の結果で、曲の音楽性や譜面の遊びやすさを保証しません。正しいBPMを入力し、生成譜面を必ず確認・調整してください。

## 音量ベース方式

音源を約10ミリ秒ごとのフレームに分け、チャンネルをまとめたRMS音量の増加をオンセット（音の立ち上がり）として検出します。BPMから計算した16分音符グリッド上で近傍のピークを調べ、難易度に応じた閾値を超えた位置にノーツを配置します。拍の表はドン、裏はカツとして出力し、強いピークは高難易度で大音符にします。

## 手元の譜面で学習・評価する

Node.js と `ffmpeg` がインストールされた環境で、データをリポジトリ外に置いたまま次を実行します。

```powershell
node tools\train-chart-model.mjs --data-dir "C:\Users\user\TJA-Gen-data"
```

最初に動作確認だけする場合は、`--limit 20`を付けてください。処理はPC内で行い、曲名や譜面、音源をネットワークへ送信しません。学習モデルと集計レポートはデータフォルダー内の`.tja-gen-training`に保存されます。

学習完了後、検証済みのモデルだけをWebアプリへ反映します。

```powershell
node tools\package-web-model.mjs "C:\Users\user\TJA-Gen-data\.tja-gen-training\model.json"
```

このコマンドは集計評価値を添えて`trained-model.js`を作成します。GitHub Pagesで誰でも使えるようにする場合は、このモデルファイルをアプリと一緒に公開します。譜面・音源・詳細レポートは公開せず、データフォルダー内に保持してください。

学習時はTJAのBPM変更・拍子変更を読み取り、分岐譜面、ディレイ、対応外の拍子やタイミング指定を含むチャートは除外します。音源のSHA-256が同じ譜面をまとめてから約20%を評価用に分けるため、同じ曲の別難易度が学習と評価にまたがりません。
