# TJA-Gen

音源と設定から太鼓の達人用のTJA譜面を生成する、依存なしのブラウザーアプリです。音源解析はブラウザー内で行います。

## 起動方法

`index.html` をモダンブラウザーで開いてください。音源はブラウザー内で処理され、サーバーにはアップロードされません。MP3などの圧縮音源を使う場合は、デコード対応のため Chrome、Edge、Firefox の利用をおすすめします。

## 使い方

1. 音源ファイルを選択します。
2. BPMは音源から自動推定されます。合わない場合は入力欄を修正します。
3. 曲名、コース、目標密度（打/秒）、1小節の最大音符数を設定します。
4. 「譜面を生成する」を押し、生成結果を確認してTJAをダウンロードします。
5. ダウンロードしたTJAと元の音源を同じフォルダーに置きます。

## 生成方式

生成方式は画面で切り替えられます。

- **学習モデル（実験版）**: `trained-model.js`の分類器が、音量特徴・拍位置・BPM・コース・密度からドン/カツ/大音符の候補を評価します。
- **音量ベース（比較用）**: 音の立ち上がりを検出し、目標密度に合わせてノーツを配置します。

目標密度は1秒あたりの打数です。各小節で音源特徴に合う位置を優先しつつ、目標打数と「1小節の最大音符数」（1〜256）に合わせます。1小節は256分割で出力します。設定密度からTJAの★レベルも概算します。BPM検出は音量の立ち上がりの周期性による推定値なので、半分/倍のBPMなどにずれる場合があります。入力欄で修正してください。

学習モデルは実験版です。評価用音源でのノーツ検出F1は約0.41で、曲の音楽性や譜面の遊びやすさを保証しません。出力譜面を必ず確認・調整してください。

## 音量ベース方式

音源を約10ミリ秒ごとのフレームに分け、チャンネルをまとめたRMS音量の増加をオンセット（音の立ち上がり）として検出します。BPMで区切った各小節を256分割し、音の立ち上がりが強い位置から目標数のノーツを選びます。拍位置によりドン/カツを割り当てます。

## 手元の譜面で学習・評価する

学習にはNode.js、`ffmpeg`、Python 3、NumPyが必要です。データをリポジトリ外に置いたまま実行します。

```powershell
node tools\train-chart-model.mjs --data-dir "C:\Users\user\TJA-Gen-data" --python "C:\Path\To\python.exe"
```

標準では学習用音源を3周して重みを更新します。動作確認は`--limit 20 --epochs 1`、学習回数を明示する場合は`--epochs 5`のように指定します。特徴量はローカルの一時ファイルに作成し、学習成功後に削除します。曲名や譜面、音源をネットワークへ送信しません。学習モデルと集計レポートはデータフォルダー内の`.tja-gen-training`に保存されます。

学習完了後、検証済みのモデルだけをWebアプリへ反映します。

```powershell
node tools\package-web-model.mjs "C:\Users\user\TJA-Gen-data\.tja-gen-training\model.json"
```

このコマンドは集計評価値を添えて`trained-model.js`を作成します。GitHub Pagesで誰でも使えるようにする場合は、このモデルファイルをアプリと一緒に公開します。譜面・音源・詳細レポートは公開せず、データフォルダー内に保持してください。

学習時はTJAのBPM変更・拍子変更を読み取り、分岐譜面、ディレイ、対応外の拍子やタイミング指定を含むチャートは除外します。音源のSHA-256が同じ譜面をまとめてから約20%を評価用に分けるため、同じ曲の別難易度が学習と評価にまたがりません。
